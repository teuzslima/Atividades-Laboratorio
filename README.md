# Atividades-Laboratorio

Atividades de Laboratório de Programação — resoluções em Python.

## Estrutura

Os exercícios estão na pasta [`exercicios/`](exercicios/), um arquivo por atividade.

| # | Arquivo | Descrição | Conceito |
|---|---------|-----------|----------|
| 01 | [exercicio_01.py](exercicios/exercicio_01.py) | Livros lidos pela turma vencedora | Variável e `print` |
| 02 | [exercicio_02.py](exercicios/exercicio_02.py) | Boas-vindas ao estudante | `input` e f-string |
| 03 | [exercicio_03.py](exercicios/exercicio_03.py) | Produção total da cooperativa | Soma de valores |
| 04 | [exercicio_04.py](exercicios/exercicio_04.py) | Média do estudante | Média aritmética |
| 05 | [exercicio_05.py](exercicios/exercicio_05.py) | Desconto promocional | Condicional `if/else` |
| 06 | [exercicio_06.py](exercicios/exercicio_06.py) | Equipamento par ou ímpar | Operador `%` |
| 07 | [exercicio_07.py](exercicios/exercicio_07.py) | Assentos de 1 a 20 | Laço `for` |
| 08 | [exercicio_08.py](exercicios/exercicio_08.py) | Total da campanha solidária | Acumulador em laço |
| 09 | [exercicio_09.py](exercicios/exercicio_09.py) | Títulos de três livros | Lista |
| 10 | [exercicio_10.py](exercicios/exercicio_10.py) | Dias da semana | Tupla (imutável) |
| 11 | [exercicio_11.py](exercicios/exercicio_11.py) | Seleção para bolsas | Condicional |
| 12 | [exercicio_12.py](exercicios/exercicio_12.py) | Radar eletrônico | Condicional |
| 13 | [exercicio_13.py](exercicios/exercicio_13.py) | Maior consumo de energia | `if/elif/else` |
| 14 | [exercicio_14.py](exercicios/exercicio_14.py) | Identificação de 1 a 50 | Laço `for` |

## Como executar

Cada exercício é executado individualmente com o Python 3:

```bash
python3 exercicios/exercicio_01.py
```
